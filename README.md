Одностраничный сайт-портфолио: рекламные видео, Telegram-боты, тексты, мобильные игры, AI-фото, нейро-поздравления и AI-песни на заказ — всё в одном файле, без сборки и внешних зависимостей.

## Структура репозитория

```
├── portfolio.html            # весь сайт: HTML + CSS + JS в одном файле
├── dji-matrice-4t-promo.mp4  # видео-кейс (реклама дрона DJI Matrice 4T)
├── README.md                 # этот файл
└── CLAUDE.md                 # инструкция для Claude Code
```

## Что внутри

- **7 каналов** — фильтр вверху сайта (видео, боты, тексты, игры, фото, поздравления, песни); клик по каналу фильтрует раздел «Проекты»
- **3 играбельные мини-игры** прямо на странице: Magic Sort (сортировка жидкости по цвету), Memory Match (карточки на память), Neon Runner (аркада-раннер)
- **Встроенное видео** — реальный кейс, а не заглушка
- Примеры текстов (стихи), плейсхолдеры для поздравлений и песен
- Анимации: плавный scroll-reveal с блюром, параллакс шкалы-тюнера, прогресс-бар скролла, объёмные hover-эффекты

## Как запустить локально

Файл не требует сборки — можно открыть `portfolio.html` прямо в браузере двойным кликом.

Если браузер блокирует что-то из-за политики `file://` (редко, но бывает с video/fetch), поднимите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000/portfolio.html
```

## Деплой

Проще всего — **GitHub Pages**:
1. Settings → Pages → Source: ветка `main`, папка `/ (root)`
2. Сайт появится на `https://ваш-логин.github.io/название-репозитория/portfolio.html`

Также подходят Netlify, Vercel, Cloudflare Pages — просто перетащить файлы, шаг сборки не нужен.

> Видео весит ~76 МБ. Это ниже жёсткого лимита GitHub (100 МБ), но если будете добавлять ещё видео-кейсы — подключите [Git LFS](https://git-lfs.com/) или храните тяжёлые файлы на отдельном хостинге (например Cloudflare R2), а в репозитории оставьте только сам сайт.
